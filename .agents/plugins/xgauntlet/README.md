# xgauntlet Antigravity Plugin

High-assurance, evidence-first development plugin for Google Antigravity IDE and CLI.

## Overview
`xgauntlet` provides multi-layer verification runners, canonical workspace state manifests, Sigstore DSSE attestations, and mutation testing gauntlets ensuring line-by-line code review becomes optional through verifiable constraints.

## Bundled Sovereign Skills
- `discover`: Socratic interview, challenging assumptions, scope bounding, and Aristotelian domain glossary in `CONTEXT.md` prior to coding.
- `spec`: Socratic requirement specification and decomposition into OKF v0.2 task packages (`tasks/<id>-<slug>.md`) with strict scope and design tokens.
- `tdd`: Strict Evidence-First Red-Green-Refactor development with local Git phase checkpoints, isolated feature tests, and prohibition of monolithic test files.
- `review`: Two-axis review (Standards vs Spec) running independent parallel sub-agents with Fowler code smells baseline.
- `diagnose`: Disciplined root-cause diagnosis loop (Reproduce -> Minimize -> Hypothesize -> Instrument -> Fix -> Regression-test).
- `release`: Release readiness audit, changelog verification (`CHANGELOG.md`), ADR coverage, and multi-digest integrity sealing.

## Execution
```bash
# Run the complete multi-layer verification gauntlet
xgauntlet verify
```
